## 📊 Comparação: Sistema de Restaurantes vs Filmes

### **Restaurantes (Original)**
```
Variáveis:       Preço, Rating, Votos, Nota da Culinária
Categorias:      5 (preço) + 4 (rating) + 5 (votos) + 3 (culinária)
Saída:           3 níveis (NA, A, MA)
Score:           1.5 - 9.5
Regras:          20+ regras combinadas
```

### **Filmes (Novo)**
```
Variáveis:       Budget, Popularity, Runtime, Vote_Average
Categorias:      5 (budget) + 4 (pop) + 3 (runtime) + 4 (voto)
Saída:           3 níveis (NR, R, MR)
Score:           2.0 - 9.0
Regras:          5-7 regras (começar simples)
```

### **Diferenças**
```
├─ Dados de entrada (CSV columns)
├─ Ranges das variáveis (budget em milhões vs reais)
├─ Regras fuzzy (específicas para filmes)
├─ Pesos de defuzzificação (pode ser diferente)
└─ Estrutura Java: Classes reutilizáveis ✓
```
